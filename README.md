# Долей!

PWA для расчёта количества топлива до полного бака и учёта заправок.

## Запуск

Нужен локальный HTTP-сервер (модули ES и Service Worker не работают через `file://`):

```bash
cd Petrol
python3 -m http.server 8080
```

Откройте `http://localhost:8080` в Safari / Chrome.

## Установка на iPhone

1. Откройте приложение в Safari
2. «Поделиться» → «На экран Домой»

## GitHub Pages

Опубликуйте корень репозитория (или папку с этими файлами). Данные пользователя хранятся в `localStorage` (`doley:v1`) и не затираются при обновлении статики. В настройках есть экспорт/импорт JSON.
